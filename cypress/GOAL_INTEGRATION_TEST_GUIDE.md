# 목표 계좌 통합 테스트 가이드

## 📋 테스트 개요

이 테스트는 목표 계좌의 **전체 라이프사이클**을 검증합니다:

### 테스트 시나리오

```
1. 자녀 👧
   ├─ 로그인
   ├─ 목표 생성 페이지 이동
   ├─ 입력 유효성 검증
   │  ├─ 빈 값 검증
   │  ├─ 금액 범위 검증
   │  └─ 저금일 검증
   ├─ 목표 정보 입력
   ├─ 예상 기간 계산 확인
   ├─ 목표 생성 요청
   └─ 대기 중인 목표 확인

2. 부모 👨
   ├─ 로그인
   ├─ 알림 확인
   ├─ 목표 요청 상세 보기
   ├─ 목표 정보 확인
   ├─ 거절 버튼 클릭
   └─ 거절 후 상태 확인

3. 자녀 👧 (재요청)
   ├─ 로그인
   ├─ 동일한 목표 재입력
   ├─ 재요청 실행
   ├─ 홈에서 중복 요청 시도
   └─ 중복 요청 실패 모달 확인

4. 부모 👨 (승인)
   ├─ 로그인
   ├─ 새 요청 알림 확인
   ├─ 승인 버튼 클릭
   ├─ 계좌 개설 플로우
   │  ├─ 정보 확인
   │  └─ 간편 비밀번호 입력
   ├─ 계좌 개설 완료
   └─ 자녀 목표 목록에서 확인

5. 자녀 👧 (상세 확인 및 수정)
   ├─ 로그인
   ├─ 목표 상세 페이지 이동
   ├─ 상세 정보 확인
   │  ├─ 목표 이름
   │  ├─ 총 금액
   │  ├─ 월 저축액
   │  ├─ 저금일
   │  ├─ 진행률
   │  └─ 계좌 번호
   ├─ 이체일 수정
   ├─ 삭제 요청
   └─ 삭제 요청 상태 확인

6. 부모 👨 (삭제 승인)
   ├─ 로그인
   ├─ 삭제 요청 알림 확인
   ├─ 삭제 승인
   └─ 목표 제거 확인
```

## 🚀 실행 방법

### 사전 준비

1. **테스트 계정 준비**
   ```
   자녀 계정: child@fisa.com / fisa123!
   부모 계정: parent@fisa.com / fisa123!
   ```

2. **개발 서버 실행**
   ```bash
   npm run dev
   ```

### 테스트 실행

#### 방법 1: Cypress UI (권장)

```bash
npm run cypress:open
```

1. **E2E Testing** 선택
2. **Chrome** 선택
3. **`goal-integration.cy.ts`** 클릭

#### 방법 2: 헤드리스 모드

```bash
npx cypress run --spec "cypress/e2e/goal-integration.cy.ts"
```

#### 방법 3: 브라우저 표시

```bash
npx cypress run --spec "cypress/e2e/goal-integration.cy.ts" --headed --browser chrome
```

## 📊 테스트 커버리지

### ✅ 검증 항목

#### 1. 입력 유효성 검증
- ✅ 빈 값 입력 시 버튼 비활성화
- ✅ 금액 범위 검증 (최소/최대)
- ✅ 저금일 유효성 (1-31일)
- ✅ 월 저축액 > 총 금액 케이스
- ✅ 숫자 포맷팅 (1,000,000)

#### 2. 목표 생성
- ✅ 목표 정보 입력
- ✅ 예상 기간 자동 계산
- ✅ 생성 요청 성공
- ✅ 성공 모달 표시
- ✅ PENDING 상태 확인

#### 3. 부모 승인/거절
- ✅ 알림 수신 확인
- ✅ 목표 정보 확인
- ✅ 거절 기능
- ✅ 승인 기능
- ✅ 계좌 개설 플로우

#### 4. 중복 요청 방지
- ✅ 이미 대기 중인 목표 있을 때
- ✅ 중복 요청 실패 모달

#### 5. 목표 상세 정보
- ✅ 목표 이름
- ✅ 총 금액
- ✅ 월 저축액
- ✅ 저금일
- ✅ 진행률 (0%)
- ✅ 계좌 번호

#### 6. 목표 수정
- ✅ 이체일 수정
- ✅ 수정 성공 메시지

#### 7. 목표 삭제
- ✅ 삭제 요청
- ✅ 부모 승인
- ✅ 목표 제거 확인

## 🔍 주요 검증 포인트

### 1. 상태 전이 확인
```
PENDING (대기) → ACTIVE (활성) → CANCELLED (삭제)
```

### 2. 알림 시스템
- 목표 생성 요청 시 부모에게 알림
- 삭제 요청 시 부모에게 알림
- 승인/거절 시 알림 상태 변경

### 3. 권한 검증
- 자녀: 생성, 조회, 수정, 삭제 요청
- 부모: 승인, 거절, 계좌 개설

### 4. UI/UX 검증
- 버튼 활성화/비활성화
- 모달 표시
- 성공/실패 메시지
- 페이지 이동

## 🛠️ 문제 해결

### 로그인 실패
```
Error: 로그인할 수 없습니다
```
**해결**: 테스트 계정이 존재하는지 확인

### 알림이 표시되지 않음
```
Error: 알림을 찾을 수 없습니다
```
**해결**: 
1. 목표 생성이 성공했는지 확인
2. 알림 API가 정상 작동하는지 확인
3. 부모-자녀 관계가 설정되어 있는지 확인

### 계좌 개설 실패
```
Error: 계좌를 개설할 수 없습니다
```
**해결**:
1. 간편 비밀번호가 올바른지 확인
2. 부모 계좌에 잔액이 충분한지 확인
3. 백엔드 API 로그 확인

### 타임아웃 에러
```
Error: Timed out retrying
```
**해결**: `cypress.config.ts`에서 타임아웃 증가
```typescript
e2e: {
  defaultCommandTimeout: 10000,
  pageLoadTimeout: 60000,
}
```
